Problem Statement & Motivation

Campus equipment breakdowns (seminar projectors, lab ACs, electrical wiring, LAN connectivity, plumbing breakdowns) are traditionally managed via manual paper logbooks or informal chat channels. This creates acute operational bottlenecks across collegiate facilities:

  • 70%+ Resolution Delays: Zero centralized dispatch or SLA tracking.
  • Zero Transparency: Students and faculty cannot track repair status.
  • Fragmented Records: Lost tickets, duplicate entries, and zero audit trail.
2
Project Objectives
  • Centralized Online Portal: Lodge verified tickets with location & category in < 60 seconds.
  • Automated Lifecycle: Manage progression: Open → In Progress → Resolved → Closed.
  • Data Integrity & Security: Server & client validation with CSRF anti-forgery tokens.
  • EF Core Code-First ORM: Relational MySQL mapping with automatic pre-seeding.
  • Operational Analytics: Live dashboard displaying resolution SLA rates and category breakdown.

5. The 7 Core .NET Concepts
1. MVC Architectural Pattern Separation
• Model: Complaint.cs & Category.cs define entities & validation.
• View: Razor views (.cshtml) render responsive UI via Tag Helpers.
• Controller: ComplaintsController.cs handles DI, routing, and actions.
2. EF Core Code-First with MySQL ORM
Configured via Pomelo.EntityFrameworkCore.MySql. Models map directly to tables with automatic seed data initialization on first launch.
builder.Services.AddDbContext<ApplicationDbContext>(opt => opt.UseMySql(connStr, ServerVersion.AutoDetect(connStr)));
3. Comprehensive CRUD Operations Lifecycle
• Create: Form POST saves new grievance with category & urgency.
• Read: Filtered dashboard lists tickets with search & status badges.
• Update: Edit action updates assigned technician and remarks.
• Delete: Confirmation view safely removes resolved tickets.
4. Form Handling & Anti-Forgery CSRF Guard
Uses strongly-typed bindings (asp-for, asp-items) and [ValidateAntiForgeryToken] protecting against CSRF exploits.
<form asp-action="Create" method="post"> @Html.AntiForgeryToken() <input asp-for="Title" class="form-control" /> </form>
5. Model Validation (Server & Client) Integrity
Enforces [Required], [StringLength(100)], [EmailAddress]. Verified server-side via ModelState.IsValid and client-side via jQuery.
[Required(ErrorMessage = "Title is required")] [StringLength(100)] public string Title { get; set; }
6. State Management (PRG Pattern) TempData
Implements TempData["SuccessMessage"] for single-use alert banners across redirects, plus HttpContext.Session for active tracking.
TempData["SuccessMessage"] = "Grievance registered!"; return RedirectToAction(nameof(Index));
7. Responsive UI Design Bootstrap 5
Mobile-first 12-column grid, responsive tables (table-responsive), flexbox alignment, 4 KPI summary cards, and status pills.
